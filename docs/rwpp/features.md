# 客户端功能

客户端以 `io.github.rwpp` 扩展运行，界面使用 Compose 绘制在游戏之上。以下内容取自 2.0.0 的实现。

## 界面

Aero 是客户端自带的界面体系。主菜单、房间、地图、战役、回放、模组与设置共用同一套控件、悬停与选中效果以及对话框动画。UI 音效有独立音量，并乘在游戏主音量之上。

界面文案通过资源提供，中英文随系统语言切换；标识与版本等固定内容保持原文。

## HUD

游戏内 HUD 可编辑：增删组件、拖动、缩放，位置按相对坐标保存，旧布局在首次启动时迁移。默认布局包含：

- 指挥台：动作排序、可用条件、队列进度、生产与撤销。
- 小地图：地形、迷雾、单位、资源点与视野框，支持点击与拖动定位。
- 资源与状态：资源、帧率、延迟、时间与生产状态。
- 观察者统计：按玩家与队伍分组，显示资金、收入与建筑价值。

单位覆盖层包含选中与悬停标记、扣血拖尾、伤害跳字、路径点与集结点。开关与 HUD 编辑器共用同一份配置。

## 房间与操控

- 房间预设：保存与加载地图和房间参数，地图缺失时给出提示。
- AI 与规则：难度继承、暂停与恢复、游戏模式、回收规则、核弹与共享控制。
- 快捷键：可搜索操作、两组绑定、原生动作名本地化。
- 镜头跟随：锁定选中组中的存活单位，死亡后轮换。
- Android 选择控件：Follow、All、Same、Types 四个可移动按钮。
- 队伍与玩家：踢出、移交、队伍调整、旁观者统计与黑名单。

小屏房间页使用整页滚动，地图与玩家列表在上、聊天在下；Middle 与 Large 保留桌面分栏。

## 战绩与回放

- 战绩入口：战役、遭遇战、多人、沙盒的本地记录，存为 TOML。
- 自动保留：默认 30 天，可选 7、30、90、365 天或永久，活动对局受保护。
- 回放档案：搜索、筛选、排序、观看、另存与批量删除。
- 回放控制：暂停、倍速、视角切换、进度定位；向后定位通过原生重载再快进。
- 对局与回放关联：新记录写入文件名，旧记录按地图与时间匹配，歧义时不建立链接。

## 沙盒与资源

- 沙盒单位编辑：所属玩家与阵营、生命、护盾、能量、弹药、朝向与施工状态。
- 附属单位：通过原生槽位安装、关联已有单位或卸载。
- 地图导出：导出房间原始地图，沙盒可包含单位位置。
- 音乐管理：浏览已加载音乐，控制播放与切换时机。
- 诊断：内存、线程、堆栈与第三方库列表。

## 联机

- 传输层：客户端优先 KCP，握手失败后回退 TCP；建立会话后不自动切换。
- 模组分发：房主启用所需模组后，客户端在进入房间时下载，失败会断开并说明原因。
- 观察者视角：显示视角与模拟队伍分离，绘制时临时切换并恢复。
- 返回房间：使用原生倒计时与事件，保留连接以开始下一局。

## 渲染

地形与水面有独立的材质、波浪与高光，后处理包含屏幕空间反射与泛光。世界绘制仍走游戏原生接口，Compose 只负责菜单与 HUD。效果可以单独关闭。

神经渲染控制器只配置并启动外部社区工具。进程运行不代表效果已生效，它也不是内置实现。

## 已知边界

- 一个进程只启动一个界面框架，声明界面框架的扩展会接管启动流程。
- 模组分发只对自行创建或托管的房间生效。
- 对局记录只覆盖本机记录过的对局，不能还原历史数据。
- 回放的向后定位依赖原生重载，不是任意时刻的内存快照。
