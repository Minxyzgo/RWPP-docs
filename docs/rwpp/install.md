# 安装 RWPP

RWPP 以扩展形式运行，因此先要有 RWML 宿主。安装顺序是宿主、API、客户端。

## 准备

- 桌面端：运行 [RWML 安装程序](https://github.com/RWPP-Team/RWML/releases/latest)，替换 `game-lib.jar`。程序会定位游戏目录，也可以手动选择。
- 扩展包：Releases 提供的整合包，或分别下载 `rwpp-api` 与 `rwpp-client`。
- Android：已安装 RWML 的 APK。
## 桌面端

1. 关闭游戏。
2. 把 `rwpp-api` 与 `rwpp-client` 的归档放入游戏目录下的 `extensions/`。
3. 通过 RWML 启动游戏。扩展页应同时列出两个扩展，标识为 `io.github.rwpp.api` 与 `io.github.rwpp`。
4. 若版本号与发行说明不一致，说明游戏仍在加载旧归档，重启一次即可。

也可以在启动器的扩展页选择“导入”，直接导入整合包 zip。整合包会逐个安装成员，已存在的相同版本被跳过。

## Android

1. 安装 RWML 的 APK，首次启动允许存储访问。
2. 在扩展管理页导入整合包，或在文件管理器中用 RWML 打开该文件。
3. 重启后进入游戏。

Android 会在扩展变化时重建 dex 缓存，首次启动会比之后慢一些。

## 用仓库安装

桌面启动器与 Android 扩展管理页都提供“浏览”页签，读取扩展目录。搜索 `RWPP` 后选择安装，目录会同时提供 API 与客户端两个归档。安装完成后重启生效。

仓库地址写在数据目录的 `repository.properties`：

```properties
index=https://rwpp-team.top/api/v1/index.json
```

## 验证

安装成功的标志：

- 启动日志出现两个 `+` 行，分别对应 API 与客户端，版本一致。
- 游戏内出现 Aero 界面，房间页、聊天与玩家列表可以打开。
- 扩展页中两个扩展都处于启用状态，且没有版本选择提示。

失败时启动器会给出具体原因。常见情形是版本不一致、归档损坏或缺少依赖，日志中的标识可以直接对应到扩展。

## 更新

两端的“浏览”页签会标出可更新的条目。安装新版本后重启游戏，旧归档在不再被占用后删除。

手工导入的扩展与仓库安装的扩展共用同一套写入规则，同一标识只保留一个版本。
