# 安装 RWPP

装好之后，游戏里会多出 Aero 界面。整个过程只要三步，不需要修改文件，也不需要记命令。

## 第一步：安装 RWML

RWPP 是 RWML 的扩展，先装好 RWML 才能使用。

- **电脑（Windows）**：到[下载页](../downloads/index.md)下载 `rwml-setup-fat.exe`，双击运行。安装程序会自己找到游戏目录，按提示完成即可。
- **手机（Android）**：安装 RWML 的 APK，第一次打开时允许它访问存储。

装完后启动一次游戏，确认游戏能正常进入。

## 第二步：在游戏里下载 RWPP

1. 打开游戏，进入**扩展**页面。电脑上是启动器的扩展窗口，手机上是扩展管理。
2. 切换到**浏览**页签，搜索 `RWPP`。
3. 在预览里点**下载**或**安装**。所需的两个扩展会一起装好，不需要分别下载。

如果更喜欢手动安装，可以从 [GitHub Releases](https://github.com/RWPP-Team/RWPP/releases/latest) 下载对应平台的 `extensions.zip` 整合包，再回到扩展页面点**导入**并选择这个文件。

## 第三步：重启游戏

关闭游戏，再重新打开。看到 Aero 界面，并且房间、聊天、玩家列表都能打开，就说明安装成功。

以后有新版本时，扩展页面的**浏览**页签会提示更新。点更新，然后重启游戏即可。

## 遇到问题

- 扩展页面里找不到 RWPP：确认 RWML 已装好，并重启一次游戏。
- 提示版本不一致：在扩展页面删除旧版 RWPP，重新下载一次。
- 仍然无法使用：加入 [玩家交流群](https://qm.qq.com/q/ncCHYxB5Ly)（927597495）询问，或到 [Issues](https://github.com/RWPP-Team/RWPP/issues) 留言。
