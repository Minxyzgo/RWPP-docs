# 资源包

资源包是一个只替换游戏资源、不运行代码的扩展。在描述符中声明 `resourcePack=true`，`mainClass` 可以省略。

```properties
id=com.example.retro
name=Retro resources
version=1.0.0
resourcePack=true
```

同一时间只有一个资源包生效。选择记录在 `data/extension-state.properties`；没有记录时，按加载顺序取第一个，其余资源包报告为禁用，并说明当前生效的是哪一个。

## 目录结构

归档根目录镜像游戏自己的资源目录：

| 路径 | 替换对象 |
| --- | --- |
| `gui/` | 界面纹理、`.rml` 文档、`.rcss` 样式与字体 |
| `units/` | 单位贴图与阴影 |
| `tilesets/` | 地形位图 |
| `music/` | 音乐 |
| `shaders/` | 着色器源码 |
| `res/drawable/`、`res/raw/` | 按资源 ID 读取的图片与音频 |

允许带 `assets/` 前缀，读取时会去掉。其他目录中的文件不会被使用，因此归档里可以同时放 `META-INF/` 与类文件。

## 生效方式

资源包只在变化时物化一次：

1. 清空 `data/resource-pack`。
2. 写入归档中的资源文件。
3. 记录包标识、版本与归档摘要。
4. 宿主启用该目录，资源读取优先查它。

下次启动若摘要一致就跳过整个步骤。没有生效的资源包时目录被清空，游戏回到自带资源。

目录中只保存资源包自己的文件。读取不到时回退到游戏，因此原版资源不会被复制，游戏更新立即生效。

## 限制

- 资源包只能替换文件，不能增加或删除游戏按目录列举的资源。
- 桌面端只通过平台资源表读取 `res/drawable` 与 `res/raw`，其他 `res` 子目录的文件会被写入但不会被请求。
- Android 按名称解析 `res` 资源，没有对应资源 ID 的文件不会加载。
- 内置模组、地图文件与翻译不会被替换；覆盖它们会破坏模组选择与语言切换。

## 选择资源包

桌面启动器的扩展页与 Android 扩展管理页都列出资源包与其他扩展。选中一个资源包后重启，新的资源目录生效；切换或取消选择同样在重启后完成，正在使用的文件不会被改写。
